## Descrição do Projeto

Sistema de quiz interativo desenvolvido em linguagem C.

O programa lê perguntas de um arquivo `.txt`,
apresenta perguntas aleatórias ao usuário,
calcula pontuação e mantém um ranking
dos melhores jogadores.

O projeto foi desenvolvido com foco em:
- manipulação de arquivos
- structs
- alocação dinâmica
- recursão
- modularização
- geração de números aleatórios

---

## Funcionalidades

- Jogar quiz
- Ver ranking
- Adicionar perguntas
- Embaralhamento aleatório
- Persistência em arquivos
- Top 10 jogadores
- Ordenação recursiva
